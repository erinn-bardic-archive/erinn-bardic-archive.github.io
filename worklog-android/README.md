# 출근콕 (안드로이드 출퇴근 기록 앱)

GPS로 직장 도착과 떠남을 감지해 출퇴근 시간을 기록하는 안드로이드 앱입니다.

## 기능

- **직장/알바처 등록**: 이름, 시급, 근무 요일 또는 특정 날짜, 출근·퇴근 시간, 휴게 시간, 위치(현재 위치·주소 검색·좌표 입력), 감지 반경, 대표 컬러
- **근무 시간 자동 계산**: `09:00 ~ 18:00 = 9시간`처럼 표시하고, 휴게시간을 빼면 실근무 시간도 보여 줌 (야간 근무 지원)
- **월급 계산기**: 시급 옆 버튼을 누르면 시급과 근무시간이 자동으로 채워짐. 일급/주급/월급/연봉을 고르고 주휴수당·4대보험 포함 여부 선택
- **도착 감지**: 직장 반경에 들어오면 도착 시간 기록 → "직장에 도착하였습니다. 근무하시겠습니까?" 알림 + 다른 앱 위 화면 가운데 팝업의 **출근** 버튼 → 누른 시간이 출근 시간
- **퇴근 카운트다운**: 퇴근 10분 전부터 1분마다 "퇴근까지 N분 남았습니다." (각 알림은 1분 안에 저절로 사라짐)
- **퇴근 시간 알림**: "퇴근시간이 되었습니다. 퇴근하시겠습니까?" → **연장 근무** / **퇴근**
- **연장 근무**: "연장 근무를 하는 당신. 퇴근하시겠습니까?" 알림이 퇴근 버튼을 누르거나 직장을 떠날 때까지 계속 떠 있음 (지워도 다시 뜸)
- **떠남 감지**: 직장 반경을 벗어나면 떠난 시간 기록. 퇴근을 안 눌렀으면 떠난 시간이 퇴근 시간으로 기록되고 연장 근무 알림도 사라짐
- **달력**: 출근한 날에 직장 컬러 점 표시. 날짜를 누르면 그날의 도착·출근·퇴근·떠남 시간, 근무시간, 일급, 메모(한 일)를 보여 줌. 기록 수정·추가 가능
- **갤럭시 핏3**: 휴대폰 알림이 Galaxy Wearable 앱을 통해 핏3로 전달됨

## 설치 (APK)

1. 이 저장소의 **Releases → `apk-latest`** 에서 `chulgeunkok.apk` 를 휴대폰으로 다운로드
2. 파일을 열고 "출처를 알 수 없는 앱 설치"를 허용한 뒤 설치
3. 앱 실행 → 오른쪽 위 톱니바퀴(설정)에서 모든 권한을 **허용됨**으로 만들기
   - 위치는 반드시 **항상 허용**
   - **다른 앱 위에 표시** 켜기 (화면 가운데 출근 팝업)
   - **배터리 최적화 제외** 켜기
4. 삼성 휴대폰: 설정 > 배터리 > 백그라운드 사용 제한 > **절전 예외 앱**에 출근콕 추가
5. Galaxy Wearable 앱 > 알림에서 출근콕 알림 켜기

## 알아둘 점

- 갤럭시 핏3는 알림을 보여 주지만, 다른 앱 알림의 버튼(출근 등)을 밴드에서 누를 수 있는지는 기기 펌웨어에 따라 다릅니다. 안 되면 폰의 알림이나 팝업에서 눌러 주세요.
- 안드로이드 14 이상에서는 어떤 앱의 알림이든 사용자가 밀어서 지울 수 있습니다. 그래서 연장 근무 알림은 지워지면 바로 다시 띄웁니다.
- GPS 오차 때문에 떠난 것으로 잘못 감지되지 않도록, 반경 밖으로 나간 뒤 몇 분(기본 3분) 동안 돌아오지 않을 때만 떠난 것으로 확정합니다. 기록에는 처음 나간 시간이 남습니다.
- 4대보험 요율은 2026년 근로자 부담분을 기준으로 한 기본값이며 설정에서 바꿀 수 있습니다. 근로소득세와 가산수당은 계산하지 않습니다.

## 서명 키 (업데이트 설치용, 선택)

서명 키는 저장소에 넣지 않습니다. 아무 설정도 안 하면 빌드할 때마다 임시 키로 서명되므로,
새 버전을 설치하려면 기존 앱을 지워야 합니다(기록도 지워짐). 기록을 유지하며 업데이트하려면
키를 한 번 만들어 저장소 **Settings → Secrets and variables → Actions** 에 넣어 두세요.

```bash
keytool -genkeypair -keystore release.keystore -alias chulgeunkok -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.keystore   # 출력값을 SIGNING_KEYSTORE_BASE64 에 저장
```

| Secret | 값 |
|---|---|
| `SIGNING_KEYSTORE_BASE64` | 위 base64 출력값 |
| `SIGNING_STORE_PASSWORD` | 키스토어 비밀번호 |
| `SIGNING_KEY_ALIAS` | `chulgeunkok` |
| `SIGNING_KEY_PASSWORD` | 키 비밀번호 |

## 직접 빌드

Android Studio에서 `worklog-android` 폴더를 열어 실행하거나 `./gradlew assembleRelease` 를 실행하세요.
